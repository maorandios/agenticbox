# AgenticBox

לקוח מייל אייג׳נטי (UI-only בשלב זה).

## הרצה

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000) — יועברו ל־`/inbox`.

## פונט

`--font-ui` מוגדר כ־`Google Sans` עם fallback למערכת.
קבצי פונט מורשים יש לשים ב־`public/fonts` ולפתוח את ה־`@font-face` ב־`src/styles/fonts.css`.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Lucide · Sonner · Radix/shadcn primitives · cmdk · motion
